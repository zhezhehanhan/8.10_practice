# 孙庆喆 8.10
+ 题目4：了解 CAN 协议帧结构
一、CAN 标准帧包含哪些字段？各占多少位？
   1. 帧起始：
        SOF，1bit显性信号（逻辑0）表示数据帧或远程帧的开始，总线空闲时才能发送。
    2. 仲裁段：
	    1.标识符位（ID）11位，ID10~ID0，按照ID10~ID0的顺序进行传输，是一个功能性的地址，CAN接收器通过标识符来过滤数据帧。
	    2.远程发送请求位（RTR）：区分数据帧还是远程帧 0数据帧 1远程帧
    2. 控制段：6位，
	    1.IDE位：1位 区分呢标准帧扩展帧  0标准格式  1扩展格式
	    2.R0位 ：1位 保留位
	    3.DLC段：4位 表示档当前报文的数据段含有多少字节，用于DLC段表示的数字为0~8
    3. 数据段：0-64位，节点要发送的原始信息，由0-8个字节组成高位先行
    4. CRC段：
     	1. CRC校验码：15位，用于校验传输是否正确
     	2. 界定符：1位 隐形位标识校验码的结束
    5. ACK段：
	    1.ACK确认位：1位，发送端的ACK确认位是隐形位（1），接收端收到正确的CRC校验位后，把这一位置为显性位（0）。
	    2.界定符：1位隐形位，用于与后面的帧结束隔开
    6. EOF段：帧结束，由发送节点发送的7个隐形位表示结束。
二、CAN 帧的 CRC 校验与本作业的校验和有什么异同？
   + 相同点：均为冗余校验，用于检测数据传输或存储中的错误,都是为发送端计算并附加在数据后，接收端重新计算并比较,不纠错，只检错，发现错误后通常请求重传。
   + 不同点：CRC校验使用模2运算比本作业中的简单累加取低八位相比更加复杂，CRC校验可以检测多位错误，出错概率比本作业中只取低八位校验出错概率小，CAN中校验使用15位，本作业校验使用8位
三、如果让你设计一个机器人内部 CAN 总线上的电机控制帧，你会怎么划分 ID 和数据段的用途？
    + ID标识符位具有11位，ID数值越小，优先级越高，因此设计机器人内部CAN总线的控制帧时，将高位作为功能码例如使电机急停，控制电机转速或者其他参数，反馈电机运行状态参数等操作，低位作为标识机器人中具体电机的地址等。
    + 数据段具有对电机的具体控制指令，要包含对电机的控制模式，在各种控制模式下要达到的目标值如力矩，速度，位置等。
